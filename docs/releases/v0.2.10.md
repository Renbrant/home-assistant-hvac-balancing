# HVAC Balancing v0.2.10

HACS distribution release for the v0.2 Python Home Assistant Custom Integration.

## Highlights

- HACS custom-repository support
- root `hacs.json` metadata
- Home Assistant local integration branding
- 256x256 `icon.png`
- 512x512 `icon@2x.png`
- HACS installation documentation
- My Home Assistant repository shortcut
- simplified pre-1.0 version numbering
- synchronized runtime and manifest versions
- automated test preventing version drift

## Controller compatibility

There are no HVAC control-policy changes in this release.

v0.2.10 retains the Production-validated behavior from v0.2.0-beta.9, including:

- dynamic balancing zones
- cooling-only Base P control
- cooling-exposure Adaptive I
- independent per-zone Adaptive deadlines
- Xtend/Tuya booster actuation
- Nest Central Assist
- persisted Central Assist ownership
- watchdog reconciliation
- historical calculated sensor entity-ID compatibility
- Recorder history continuity

## Validation

- 182 automated tests passed
- 22 subtests passed
- Python compilation passed
- repository diff validation passed
- HACS repository structure validated locally

## Production transition

The existing v0.2.0-beta.9 Production installation remains the reference controller until the v0.2.10 HACS installation/upgrade path is validated.

After the GitHub release is published, v0.2.10 will be used to validate:

- HACS custom repository discovery
- HACS installation
- upgrade from the existing Production integration
- preservation of the existing Home Assistant configuration entry and entities
