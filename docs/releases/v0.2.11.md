# HVAC Balancing v0.2.11

Targeted Production tuning release for the Home Assistant HVAC Balancing HACS integration.

## Controller change

Central Assist now activates only when at least one zone reaches final PI target **Speed 10**.

Previous behavior:

    Speed 8 or higher -> Central Assist

New behavior:

    Speed 0-8 -> local booster only
    Speed 10  -> local booster at maximum demand + Central Assist

This makes the central HVAC blower a last-stage airflow reinforcement and reduces unnecessary acoustic disturbance.

## Deliberately unchanged

- Base P curve and hysteresis
- Adaptive I behavior
- maximum booster speed
- five-minute Central Assist release grace
- cool/idle controller semantics
- Nest fan-timer adapter and ownership behavior
